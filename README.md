# Hi, I'm Peet

**Dev & Explorer** · Thailand

Manufacturing graduate. Self-taught engineer. Three years in software — still leveling up.

I graduated in **manufacturing engineering**, then taught myself to code because I wanted to build the tool, not only describe the problem. No CS degree — just shipping, breaking, reading, and shipping again.

Three years into software, I am stretching from “I can build a feature” toward **owning work end to end**: the interface, the API, the data, and the box it runs in. TypeScript is the through-line — React and Next.js on the front, NestJS and Node on the back. Arduino still shows up when a system has to live in the real world.

The project that marks that shift is **[CX Support Agent](https://github.com/ThePeetMan/cx-support-agent)**: RAG, tool-using agents, an embeddable widget, and a path to a human when the bot should stop. I am using it to raise my own bar — not only write code, but leave a product slice someone else can run.
